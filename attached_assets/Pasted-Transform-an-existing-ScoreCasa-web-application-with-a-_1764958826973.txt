Transform an existing ScoreCasa web application with a modern, visually striking design system while preserving all current functionality and content structure. Apply contemporary styling, effects, and visual hierarchy to elevate the user experience.
Design Philosophy
Update the existing application to feel premium, data-driven, and futuristic while maintaining familiar layouts and navigation patterns. Focus on visual polish through lighting effects, gradients, and refined typography.
Color System & Background

Primary Background: Deep gradient from dark navy to teal-tinged navy (#1a1530 → #0f1f3d → #1a3a52)
Gradient Direction: Left to right, with the teal/cyan influence increasing toward the right side
Accent Colors:

Primary: Bright cyan (#00d9ff) for interactive elements and key highlights
Secondary: Vibrant purple/magenta (#a855f7, #d946ef) for CTAs and emphasis
Tertiary: Electric blue accents for badges and status indicators



Typography Updates

Headlines: Bold, modern sans-serif (e.g., Inter, DM Sans, or similar)

Large headlines: 56-72px, letter-spacing: -0.02em
"Value" in cyan (#00d9ff), "of Home" in purple gradient (#a855f7 → #d946ef)


Body Text: Light gray (#a0aec0) for readability on dark backgrounds
Metric Numbers: Extra bold, 36-48px for emphasis
Subtext: Muted gray (#64748b) at 14-16px

Glow & Lighting Effects
Hero Section Glow

Primary Glow: Radial gradient emanating from the house icon

Inner core: Cyan at 60% opacity, 200px radius
Mid-range: Cyan at 30% opacity, 400px radius
Outer ambient: Cyan at 8% opacity, 600px radius


House Icon: Cyan stroke with subtle inner glow and outer shadow
Apply filter: drop-shadow(0 0 40px rgba(0, 217, 255, 0.5))

Badge & Status Indicators

Small badges ("+4.2%", "Secure", "Elite", "+12% YoY"):

Border: Cyan with 1px stroke
Background: Semi-transparent with backdrop blur
Glow: box-shadow: 0 0 20px rgba(0, 217, 255, 0.3)



Card Components

Background: Dark semi-transparent cards (#1e1e3f with 40% opacity)
Border: Subtle 1px border in dark blue (#2d3a5e)
Hover State: Increase border brightness to cyan, add soft glow
Glass Effect: Apply backdrop-filter: blur(10px) for modern glassmorphism
